About the DAMM Project

System overview, architecture, and roadmap.

What DAMM Does

  • Lets developers upload AI models with metadata, pricing, and evaluation metrics.
  • Stores model artifacts on IPFS through the Pinata gateway — permanent, censorship-resistant.
  • Allows users to buy and download models using MetaMask wallet identity.
  • Issues a runtime passkey at buy-time, required for every prediction call.
  • Provides a public contribution workflow with community proposals and upvotes.

Current Architecture

  • Frontend: Vanilla HTML/CSS/JS pages — marketplace, upload, predict, contribute.
  • Auth: MetaMask wallet — your Ethereum address is your identity. No passwords.
  • Backend: FastAPI service for upload, buy, predict, proposals, and registry.
  • Storage: IPFS (Pinata) for model files + Neon PostgreSQL for purchase records.
  • Inference: Passkey-verified prediction endpoint (currently deterministic placeholder).

Roadmap

  • ✓ Phase 1 (Now): MetaMask wallet auth, XSS fixes, PostgreSQL registry, price display, dark UI.
  • ⟳ Phase 2 (Next): Sepolia testnet smart contract — on-chain model registry + ETH payments.
  • ⟳ Phase 3 (Next): ERC-721 NFT issued per purchase — replaces passkeys with on-chain ownership proof.
  • ⟳ Phase 4 (Next): Real ONNX model inference replacing SHA256 placeholder.
  • ✦ Future: Decentralized compute via Akash Network for permissionless inference.
  • ✦ Future: Fully on-chain model registry replacing backend JSON/PostgreSQL.
